# 🦉 Noetic Math Quest

Live: **https://borenw.github.io/noetic-math-kids/** (also at `/noetic.htm`)

Interactive puzzle practice for an 8-year-old (2nd–3rd grade), in the style of the Noetic Learning
math contest: thinking problems, not big sums.

- **Practice contest**: 10 random problems, one from each of 10 puzzle types.
- **Topic practice**: 5 problems of one kind.
- 16 puzzle types: number patterns, repeating shapes, ages, coins, chickens & cows, line-ups,
  fence posts, counting squares, balance scales, time, make-a-list, fruit equations, cutting logs,
  page digits, fair share, stairs.
- Every problem is generated fresh, so replays are different.
- Hands-on helpers (leg slider, line builder, tap-to-count coins, square highlighter, candy sharing),
  💡 hints, 📖 step-by-step answers, 🔊 read-aloud, ✏️ scratch paper, ⭐ stars.

One self-contained HTML file. `index.html` and `noetic.htm` are identical copies.
Not affiliated with Noetic Learning.
